# 🎂 Happy Birthday

A fun, animated happy-birthday web page with festive visuals, background music, and decorative effects — built as a personal celebration project.

## ✨ Features

- Animated birthday banner and decorative string lights (multi-color bulbs)
- Background birthday music (`hbd.mp3`)
- Custom cake illustration and vine/balloon decorations
- Lightweight animation effects via `effect.js` and `cake.less`

## 🧰 Tech Stack

HTML, CSS (LESS), JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/AmnaKhan1323/happy-birthday.git
cd happy-birthday
# Open index.html directly in your browser
```

No build step or dependencies required — it's a static page.
